# @dumbdashboards

Interactive HTML dashboards on pop culture and sports.

**Browse them all: https://dumb-dashboards.github.io/dumb-dashboards/**

Every dashboard is a single `.html` file in this repository: open it from the page above, or download the file and run it locally (just double-click it).

All of my dashboards are free to use and download, and are created without any commercial purposes! Please mention @dumbdashboards if you refer to any of my projects.
